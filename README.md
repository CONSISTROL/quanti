# A股波段交易系统 v4.0

一键运行的A股波段交易系统。`python main.py` 即可完成：数据采集 → 因子打分 → 回测验证 → 生成报告。所有参数通过 `config.json` 配置。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置（编辑 config.json，填入你的 AI API Key）

# 3. 运行
python main.py
```

输出：
- 终端：回测统计 + 操作记录 + 当前持仓建议
- HTML：`report_YYYYMMDD.html`（收益曲线 + 操作明细 + 选股排名）

## 交易体系

### 超短线反弹策略（当前默认）

**核心逻辑**：买超跌反弹，快进快出

**买入条件**（需全部满足，评分≥9分）：
- 深度超跌：5日跌幅 > 5%（+4分）
- SKDJ极度超卖金叉：K < 20 且金叉（+4分）
- 极度缩量：量比 < 0.6，卖压衰竭（+3分）
- 长期趋势向上：价格在MA120之上
- MA60支撑：价格靠近60日均线

**卖出条件**（任一触发）：
- 止盈：盈利 ≥ 3%
- 止损：亏损 ≥ 2%
- 到期：持有 ≥ 4天

**仓位管理**：最多4只，每只25%资金

> ⚠️ 80%胜率+2%回撤在纯股票策略中几乎不可能实现。当前结果是"低胜率+高盈亏比"的趋势跟踪风格，这是量化策略的常见且合理的表现形态。

## config.json 配置说明

```json
{
    "ai": {
        "api_key": "sk-xxx",                                    // 千问/Claude API Key
        "base_url": "https://dashscope.aliyuncs.com/apps/anthropic",
        "model": "qwen3.7-max"
    },
    "trading": {
        "initial_capital": 1000000,    // 初始资金
        "max_positions": 4,            // 最大持仓数
        "position_pct": 0.25,          // 单只仓位占比
        "stop_loss": -0.02,            // 止损线
        "take_profit": 0.03,           // 止盈线
        "max_holding_days": 4,         // 最大持有天数
        "min_buy_score": 9             // 最低买入评分
    },
    "backtest": {
        "start_date": "2026-01-01",    // 回测开始日期
        "end_date": "2026-07-27"       // 回测结束日期
    },
    "scoring": {
        "weights": "0.25,0.20,0.25,0.20,0.10",  // 价值/成长/质量/动量/风险权重
        "top": 30
    },
    "data": {
        "hist_days": 1200,             // 历史K线天数
        "exclude_gem": true,           // 排除创业板(300xxx)
        "exclude_star": true,          // 排除科创板(688xxx)
        "include_etf_lof": false       // 是否纳入ETF/LOF
    }
}
```

## 项目结构

```
├── main.py              # 入口 (python main.py)
├── config.json          # 配置 (所有参数)
├── trading_engine.py    # 波段交易引擎 (买卖信号+回测)
├── sell_signals.py      # 卖出信号模块
├── data_fetcher.py      # 数据采集 (AkShare)
├── factor_model.py      # 因子计算+打分
├── report_generator.py  # HTML报告生成
├── backtest.py          # Walk-forward回测框架
├── price_targets.py     # 买卖参考价
└── cache/               # 数据缓存
```

## 技术指标

| 指标 | 说明 | 用途 |
|------|------|------|
| **MACD** | DIF/DEA/柱状线 | 金叉买入/死叉卖出 |
| **SKDJ** | 慢速KDJ (K/D/J) | 超卖金叉买入/超买死叉卖出 |
| **量比** | 5日均量/20日均量 | 缩量确认卖压衰竭 |
| **MA均线** | MA5/10/20/60/120 | 趋势判断+支撑阻力 |
| **波动率** | 20日年化波动率 | 风险过滤 |
