# A股波段交易系统 v4.0

一键运行的A股波段交易系统。`python main.py` 即可完成：数据采集 → 因子打分 → 回测验证 → 生成报告。所有参数通过 `config.json` 配置。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置（编辑 config.json，填入你的 AI API Key）

# 3. 运行
python main.py
```

输出：
- 终端：回测统计 + 操作记录 + 当前持仓建议
- HTML：`report_YYYYMMDD.html`（收益曲线 + 操作明细 + 选股排名）

## 运行模式

### 1️⃣ 全市场扫描回测（默认）

```bash

```

全市场 2700+ 只股票按综合评分排名，用当前策略回测整个市场，输出统计与持仓建议。

### 2️⃣ 个股回测 ⭐

**回测单只股票的完整买卖信号**（100% 满仓、不启用凯利公式）：

```bash
python main.py --stock 601857      # 中国石油
python main.py --stock=000001      # 也支持 = 号写法
python main.py --stock sh601857    # 带交易所前缀也可
```

**用法说明：**
- 参数：`--stock` 后跟 6 位股票代码（自动去除 sh/sz/bj 前缀并补零）
- 回测区间：取 `config.json` 中 `backtest.start_date / end_date`（默认 2025-01-01 ~ 2026-07-27）
- 交易规则：单只股票、100% 满仓进出、当天收盘价成交（T+1 生效）
- 输出：终端显示完整统计（总收益/Sharpe/回撤/胜率/盈亏比）+ 每笔操作记录（含累计收益、总市值、仓位、信号原因）
- 报告：生成 `report_<代码>_<日期>.html`，含净值曲线（买卖点标记）、盈亏分布、操作记录表、回测摘要

## 交易体系

### 弱转强趋势策略（当前默认）

**核心逻辑**：周线级别确认底部（低位金叉）后重仓买入，持有到高位转弱卖出。

**买入条件**（需全部满足，评分≥4。周线定趋势定触底、日线定买卖点，右侧交易）：

*周线触底四要素*：
1. **周线SKDJ触底**（必须）：动态周线 K<20 且 0<K-D<5（K 刚上穿 D，股价触底）
2. **周线超卖**（必须）：价格贴近/低于周线BOLL下轨（价/下轨 < 1.05）— 未跌透的假触底不做
3. **周线MACD止跌**（必须）：周线 DIF-DEA 较前日增长，且非深死叉（DIF-DEA ≥ -0.02）
4. **周线MA5止跌**（加分）：周线 MA5 拐头向上（+1分）

*日线买卖点*：
5. **日线MACD金叉**（必须）：MACD 阴转阳金叉（DIF 上穿 DEA，3 日窗口），或右侧确认（MA5 止跌转涨 且 DIF-DEA 较前一日上涨，金叉趋势已现）
6. **日线SKDJ近3天无死叉**（必须）：SKDJ 死叉时禁止买入
7. **日线SKDJ非高位**（必须）：K>65 不买（不在高位追入）
8. 加分项：日线 SKDJ 低位金叉（K<40）、跌破周线下轨（深度超卖）、**跌破日线BOLL下轨（日线超卖，可做反弹）**、周线MA5拐头、MA5 拐头向上、综合排名 TOP10（+2分）

**短线超跌反弹买点**（独立买点，日线BOLL明显超卖）：
1. 收盘价**明显跌破日线BOLL下轨**（价/下轨 < 0.97，深跌破轨=明显超跌，刚跌破不算）
2. **当日跌幅 ≥ 4%**（急跌超卖，非阴跌 — 区分"超跌反弹"与"下跌中继"）
3. **周线SKDJ K<20**（周线级别超卖确认）
4. 卖出：**反弹到日线BOLL中轨（MA20）** 或 **持有 5 个交易日到期**，止损-5%
5. 示例：000567 2025-04-07 跌停深跌破轨（-10.1%，低于下轨 5.5%）→ 04-14 反弹卖出 +14.4%；而 01-03 仅低于下轨 1.6%（未明显超跌）不触发

**卖出条件**（任一触发）：
1. 日线 SKDJ 高位死叉：K>60 且 K 下穿 D
2. 周线 SKDJ 高位死叉：K>60 且 K 下穿 D（最强信号）
3. 止损：-5%

> 同日规则：卖出当天不买回（避免同日换手白交手续费）

**仓位管理**：最多 4 只；启用凯利公式（`kelly_mode`）时按历史盈亏动态分配，否则每只 25% 资金

**回测示例（中国石油 601857，2025-01-01 ~ 2026-07-27）**：

```

年化收益:   +25.40%
Sharpe:     2.30
最大回撤:   3.1%
交易次数:   4 笔
胜率:       100%
```

> 💡 提示：个股回测中买入/卖出信号会在终端与 HTML 中给出信号原因（如"周线低位金叉(K=6)+MACD阴转阳金叉"），可用于核对你的行情软件判断。

## config.json 配置说明

```json
{
    "ai": {
        "api_key": "sk-xxx",                                    // 千问/Claude API Key
        "base_url": "https://dashscope.aliyuncs.com/apps/anthropic",
        "model": "qwen3.7-max"
    },
    "trading": {
        "initial_capital": 150000,      // 初始资金
        "max_positions": 4,             // 最大持仓数
        "position_pct": 0.25,           // 单只仓位占比（未启用凯利时）
        "kelly_mode": true,             // 凯利公式动态仓位
        "stop_loss": -0.03,             // 止损线
        "take_profit": 0.08,            // 止盈线
        "max_holding_days": 0,          // 最大持有天数（0=不限制）
        "min_buy_score": 4,             // 最低买入评分
        "strategy": "reversal"          // 策略: reversal(弱转强) / momentum(动量)
    },
    "backtest": {
        "start_date": "2025-01-01",     // 回测开始日期（个股回测也使用此区间）
        "end_date": "2026-07-27",       // 回测结束日期
        "strategy": "composite",
        "compare_strategies": true
    },
    "scoring": {
        "weights": "0.25,0.20,0.25,0.20,0.10",  // 价值/成长/质量/动量/风险权重
        "top": 30
    },
    "data": {
        "hist_days": 1200,             // 历史K线天数
        "workers": 8,                  // 数据下载并发数
        "include_etf_lof": false,      // 是否纳入ETF/LOF
        "exclude_gem": true,           // 排除创业板(300xxx)
        "exclude_star": true           // 排除科创板(688xxx)
    }
}
```

## 技术指标

| 指标 | 说明 | 用途 |
|------|------|------|
| **MACD** | DIF/DEA/柱状线 | 金叉买入/死叉卖出 |
| **SKDJ** | 慢速KDJ (K/D/J) | 超卖金叉买入/超买死叉卖出 |
| **周线SKDJ** | 按自然周聚合的动态周线 | 周线低位金叉确认底部 |
| **量比** | 5日均量/20日均量 | 缩量确认卖压衰竭 |
| **MA均线** | MA5/10/20/60/120 | 趋势判断+支撑阻力 |
| **波动率** | 20日年化波动率 | 风险过滤 |
