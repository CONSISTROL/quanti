# A股多因子量化选股系统 v3.0

基于五大因子（价值/成长/质量/动量/风险）的量化选股模型，支持**个股 + ETF/LOF**混合筛选，提供**买卖参考价**、**策略回测**和**指定日期模拟选股**功能。内置 AI 策略分析（通义千问/Claude），自动给出优化建议。

## 功能一览

| 功能 | 说明 | 命令 |
|------|------|------|
| 📊 多因子选股 | 五大因子打分排名全A股 | `python main.py --no_history` |
| 🏦 ETF/LOF | 纳入全市场1500+只基金 | `--include_etf_lof` |
| 💰 买卖参考价 | PE/PB分位数 + 技术面支撑阻力 | `--price_targets` |
| 🔬 策略回测 | Walk-forward验证策略有效性 | `--backtest` |
| 🏆 多策略对比 | 5种策略横向PK | `--backtest --compare_strategies` |
| 🕰️ 指定日期选股 | 模拟历史某天应买什么，并验证收益 | `--backtest_date 2026-03-30` |
| 🤖 AI策略分析 | 调用千问/Claude分析回测结果 | `--compare_strategies` + config.json |

## 5种内置策略

| 策略 | 参数 | 逻辑 | 适合风格 |
|------|------|------|---------|
| **复合策略** | `composite` | 动量30% + 趋势30% + 低波20% + 低回撤20% | 均衡（默认推荐） |
| **动量策略** | `momentum` | 买入近期涨幅最大的（1/3/6月加权） | 激进追涨 |
| **反转策略** | `reversion` | 买入近期跌幅最大的（逆向投资） | 抄底 |
| **趋势策略** | `trend` | 均线之上 + 均线多头排列 + 动量 | 稳健趋势 |
| **低波动策略** | `low_vol` | 买入波动率和回撤最小的 | 保守防守 |

## 选股逻辑

### 过滤规则
- **股票**：自动排除 ST/*ST、停牌、北交所、亏损股(EPS≤0)
- **ETF/LOF**：排除停牌(成交量=0)、规模过小(流通市值<1亿)

### 因子计算
1. **价值因子**（仅股票）：EP(1/PE)、BP(1/PB)、SP(1/PS) — 越高越便宜
2. **成长因子**（仅股票）：营收同比增长率、净利润同比增长率 — 越高越好
3. **质量因子**（仅股票）：ROE、毛利率 — 越高越好
4. **动量因子**（通用）：1月/3月/6月收益率 — 越高越强
5. **风险因子**（通用）：60日波动率(取反)、最大回撤(取反) — 得分越高越稳（正数=低风险，负数=高风险）

### 打分方法
1. **缩尾处理**：5%~95%分位数截断极端值
2. **Z-score标准化**：统一量纲
3. **加权综合**：按因子权重求组内平均再加权求和
4. **缺失惩罚**：因子缺失的证券按可用比例的平方根打折
5. **ETF/LOF**：仅动量+风险因子，权重自动归一化使分数与股票可比

### 买卖参考价
- **股票**：PE/PB历史分位数 + 同行业PE中位数修正 + 技术面支撑阻力（MA/Bollinger/高低点）
- **ETF/LOF**：价格历史分位数 + MA均线 + Bollinger Bands
- **输出**：买入区间(低估值)、卖出区间(高估值)、支撑位、阻力位、PE百分位

### 回测框架
- **Walk-forward**：每个再平衡日重新计算因子→打分→选TOP N→计算前瞻收益
- **市场过滤**：可选开启牛熊判断（>30%股票在MA60之上时才买入）
- **基准**：全市场等权平均收益
- **指标**：胜率、平均收益、中位数收益、Sharpe比率、最大回撤、超额收益

## 常见问题

**Q: 首次运行很慢？**
A: 完整模式需获取~3700只股票的历史K线，约30分钟。建议首次用 `--no_history` 快速体验，之后运行完整模式（数据会缓存）。

**Q: 回测胜率为什么不高？**
A: 量化策略通常"赚大亏小"，胜率低但盈亏比高。关注 Sharpe 比率和超额收益更有意义。

**Q: 如何让回测更精确？**
A: 用 `--hist_days 1200 --no_cache` 获取更长历史数据，增加回测周期数。

**Q: AI分析没触发？**
A: 确保 `config.json` 中配置了 `ai.api_key`，并使用 `--compare_strategies` 模式。
